CSS 优先级演示

将此文件保存为 index.html，直接在 VS Code 用 Live Server 或浏览器打开即可。

1) 元素选择器 p（应为 green）

我来自 p 规则（green）

2) class 覆盖元素（应为 blue）

我被 .cls 覆盖（blue）

3) 同 specificity（p.cls），后写覆盖（应为 salmon）

我是 p.cls，后写的 p.cls 将我设为 salmon

4) 多个 class 更具体（应为 purple）

.note.warning specificity 更高（purple）

5) #id 覆盖 .class（应为 red）

同时有 #uid 与 .cls，最终 red

6) 行内样式覆盖普通规则（应为 deeppink）

行内 style 比 .cls 更高（deeppink）

7) .force 的 !important 覆盖行内（应为 black）

尽管有行内 deeppink，但被 .force !important 覆盖为 black

8) 同一选择器重复定义，后写覆盖（应为 teal）

.late 定义两次，后写 teal 覆盖先写 brown（teal）

9) 父级限定使 .box .btn 背景 gold；单独 .btn 为 silver
